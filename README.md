# 🦖 DinoVerse

**DinoVerse** is an interactive digital experience designed to explore and engage users in a dynamic prehistoric environment through immersive interaction and intuitive design.

---

## 🚀 Overview

DinoVerse is developed as a Human-Computer Interaction (HCI) project that focuses on creating an engaging and user-centered experience.  
It combines interactive elements with immersive design principles to simulate a compelling dinosaur-themed environment.

The project emphasizes usability, interaction flow, and visual engagement, aiming to deliver a seamless and intuitive user experience.

---

## ✨ Features

- 🧭 Interactive user experience design  
- 🦕 Immersive dinosaur-themed environment  
- 🎮 Real-time interaction and navigation  
- 🎨 Clean and intuitive UI/UX
